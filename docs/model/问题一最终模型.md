## 1 题意与建模目标

### 1.1 题目原文要点（问题一）

给定典型日的负荷功率、光伏预测功率与分时电价，要求微网在每天 0:00 一次性排定全天 144 个 10 分钟时段的购电量与储能充放电动作，使全天购电费用最小，并保证日初与日末储电量相同。

### 1.2 关键判定

1. **确定性**：电价、负荷、光伏在日内均视为确定量，不含随机性；
2. **不可售电**：微网只向外部电网购电，不向电网售电；
3. **允许弃光**：无法被负荷或储能吸收的富余供能可以不利用（引入非负未利用供能变量）；
4. **日末闭环**：$E_0 = E_T = 6000$ kWh，严格相等；
5. **储能约束齐全**：容量区间、充放电功率上限、单程效率同时生效，不能简化为无约束峰谷套利；
6. **目标唯一**：$J_1 = \sum_t c_t g_t$，以 kWh 电量直接乘电价，不再重复乘时间步长。

### 1.3 交付清单

1. `result1.xlsx`：题目表 1（指定时段购电量与全天结果）、表 2（六个 4 h 区间充放电量与首末储电量）；
2. 全年最优费用与关键中间量：`results/q1_summary.json`；
3. 对偶与影子价格证据：`results/q1_summary.json` + `results/q1_layer_comparison.md`；
4. 价值函数曲线与审计：`results/q1_value_function_audit.csv`、`figures/result_q1_value_function.png`；
5. 灵敏度扫描：`results/q1_sensitivity.json` / `q1_sensitivity_wide.csv`；
6. 逐时段调度明细：`results/q1_dispatch_10min.csv`；
7. 结果模板映射审计：`results/q1_result1_mapping_audit.csv`。

## 2 模型假设

1. **单一电价信号**：附件 1 给定的分时电价即外网购电电价，日内不随时间再波动；
2. **确定性环境**：负荷与光伏预测值即真实值，问题一不考虑预测偏差；
3. **效率恒定**：充电与放电单程效率同为 $\eta = 0.9$，不随 SOC 或功率变化；
4. **不计损耗外因素**：不计自放电、爬坡约束与电池循环退化成本；
5. **交流侧计量充放电**：$C_t, D_t$ 为交流侧电量，$E_t$ 为电池内部储电量；
6. **不允许售电**：$g_t \ge 0$，富余供能只能转入未利用供能 $w_t$；
7. **时间取整口径**：附件采用区间末标记，第 $t$ 段对应 $[(t-1)\Delta t,\ t\Delta t)$，$\Delta t = 1/6$ h。

## 5 主模型：确定性线性规划

### 5.1 决策变量与约束

决策变量为 $g_t, C_t, D_t, w_t$（$t=1,\dots,T$）与 $E_t$（$t=1,\dots,T$）。

**供能覆盖**（供给不低于负荷与充电需求，引入 $w_t \ge 0$ 后写成等式）：

$$g_t + V_t + D_t = L_t + C_t + w_t \tag{2}$$

**储能状态递推**（充放电在交流侧核算，储电量在电池内部核算）：

$$E_t = E_{t-1} + \eta\,C_t - \frac{D_t}{\eta} \tag{3}$$

**容量与功率限制**：

$$1200 \le E_t \le 10800,\qquad 0 \le C_t,\ D_t \le S,\qquad g_t,\ w_t \ge 0 \tag{4}$$

**日末闭环**：$E_T = E_0 = 6000$。

### 5.2 目标函数与求解规模

$$\min\ J_1 = \sum_{t=1}^{T} c_t\,g_t \tag{5}$$

保留 $E_0$ 为变量时模型含 721 个连续变量、288 条等式约束；消去 $E_0$ 后为 720 个连续变量。模型为**纯线性规划**，无需整数变量。用 `scipy.optimize.linprog(method="highs")` 调用 HiGHS：

| --- | ---: |
| 求解状态 | Optimization terminated successfully（HiGHS Status 7: Optimal） |

| 全天购电量 | **59482.69899835391 kWh** |

| tie-break | 未启用（`not_needed`） |

### 5.3 命题 1（互斥最优解的存在性）

> **命题 1**　在电价非负、单程效率 $\eta<1$、允许未利用供能、日末闭环四个条件下，问题一存在一个同一时段充放电量不同时为正的最优解。

**证明要点**：任取可行解，考察某 $C_t>0$ 且 $D_t>0$ 的时段，令

$$\varepsilon = \min\left\{C_t,\ \frac{D_t}{\eta^2}\right\} > 0,\qquad
\tilde C_t = C_t - \varepsilon,\qquad \tilde D_t = D_t - \eta^2\varepsilon \tag{6}$$

则内部电量增量不变（$\eta\tilde C_t - \tilde D_t/\eta = \eta C_t - D_t/\eta$），储量边界仍满足；而交流侧净用电 $C_t - D_t$ 释放出 $x = (1-\eta^2)\varepsilon > 0$，将其优先冲减购电量后费用变化 $\Delta J = -c_t\min\{g_t,x\} \le 0$。由 $\varepsilon$ 的取法，$\tilde C_t$ 与 $\tilde D_t$ 至少一个为 0。逐一处理各时段即得费用不高于原值、处处互斥的可行解。$\square$

**推论**：LP 松弛的最优解集包含互斥最优解，故其最优值等于含互斥约束模型的最优值。命题保证的是"互斥最优解存在"，不保证每个退化最优解都互斥。

**数值证书**：本问求解所得解直接满足

$$\sum_{t=1}^{144} c_t d_t = 0,\qquad \max_t \min(c_t, d_t) = 0$$

即全天没有任何时段同时充放电（`max_simultaneous_charge_discharge_kwh = 0.0`、`sum_charge_times_discharge_kwh2 = 0.0`）。该等式只作为 LP 解的事后证书，不作为非线性约束。

> **适用边界**：一旦不允许弃电、允许售电、加入循环或退化成本、或电价可为负，同时充放电可能变得有利，命题 1 不再成立，必须回到混合整数模型。

## 6 对偶视角：等效内部电价与影子价格

### 6.1 内部等效电价

对供能约束（2）取乘子 $\pi_t$、对状态递推（3）取乘子 $\lambda_t$，得互补松弛条件

$$0 \le \pi_t \le c_t,\qquad g_t\,(c_t - \pi_t) = 0,\qquad \pi_t\,w_t = 0 \tag{7}$$

即：**只要在购电，内部电价就等于外网电价**；一旦光伏或储能足以覆盖需求，内部电价降到外网电价以下而不购电；出现未利用供能时内部电价为 0。实测 $\pi_t \in [0.371300,\ 1.256100]$，且满足 $0 \le \pi_t \le c_t$（`True`）。

**表 6-1 指定时段的外网电价、内部等效电价与计划购电量**

| 时间段 | 外网电价 $c_t$ / (元/kWh) | 内部电价 $\pi_t$ / (元/kWh) | 计划购电量 / kWh |
| --- | ---: | ---: | ---: |
| 10:00—10:10 | 0.9919 | 0.4785 | 0.000000 |
| 12:00—12:10 | 0.4411 | 0.4411 | 480.412450 |
| 14:00—14:10 | 1.0002 | 0.4785 | 0.000000 |
| 16:00—16:10 | 0.8271 | 0.8271 | 445.431650 |
| 18:00—18:10 | 1.2561 | 1.2561 | 531.894050 |
| 20:00—20:10 | 1.3513 | 1.2561 | 0.000000 |

12:00、16:00、18:00 三个时段 $\pi_t = c_t$（仍在购电）；10:00、14:00、20:00 外网电价虽高（0.99—1.35 元/kWh），内部电价却低至 0.4785 / 1.2561 元/kWh，说明由光伏或储能放电供给更划算，故购电量为 0。**"外网电价高但内部价格低"正是储能被调用的信号。**

### 6.2 动作判别准则

充电的约化成本为 $\pi_t - \eta\lambda_t$，放电的约化成本为 $-\pi_t + \lambda_t/\eta$：当 $\pi_t < \eta\lambda_t$ 时倾向充电，$\pi_t > \lambda_t/\eta$ 时倾向放电，介于两者之间储能静止。此外，1 kWh 外购电经"充—放"完整循环后仅剩 $\eta^2 = 0.81$ kWh，故纯套利要求后期电价高于前期电价的 $1/\eta^2 \approx 1.23$ 倍。

### 6.3 设备参数的边际价值

把同一设备参数对应的全部边界乘子求和，得到"统一放宽该参数 1 单位"的局部边际收益：

| 容量上限 +1 kWh | 0.6550455555555555 元 | 21 |
| 运行下限 −1 kWh | 0.659378888888889 元 | 8 |
| 共同充放电限额 +1 kWh | 0.33879999999999977 元 | 19 |
| 折合额定功率 +1 kW | 0.05646666666666662 元 | — |

放电功率上界的独立边际值为 0，说明当前瓶颈主要是**可用容量与充电速度**，而非放电速度。对上述参数分别作 1 单位单边扰动，费用差与对偶估计的最大误差仅 $4.23\times10^{-12}$ 元（`max_dual_finite_difference_error_yuan = 4.226841099352896e-12`），验证了影子价格解释。全天有效充电时段 45 个、放电时段 37 个、未利用供能时段 0 个。

## 7 第二层：连续状态动态规划

LP 对偶解在退化点未必唯一，且单次求解只给出当前参数附近的局部边际信息。连续状态 DP 以储电量为唯一状态，一次给出**整个可行区间**上的价值函数。

### 7.1 递推结构

由命题 1 可只在互斥解中寻优。记 $x_t = E_t - E_{t-1}$，交流侧净用电为分段函数

$$\psi(x) = \begin{cases} x/\eta, & x \ge 0\ (\text{充电})\\[2pt] \eta x, & x < 0\ (\text{放电})\end{cases} \tag{8}$$

给定增量 $x_t$，满足供能覆盖的最少购电量与费用为

$$g_t = [\,n_t + \psi(x_t)\,]^{+},\qquad \varphi_t(x) = c_t\,[\,n_t + \psi(x)\,]^{+} \tag{9}$$

Bellman 递推：

$$F_t(e) = \min_{e'}\big\{\varphi_t(e'-e) + F_{t+1}(e')\big\},\qquad
F_{T+1}(e) = \begin{cases}0, & e = 6000\\ +\infty, & e \neq 6000\end{cases} \tag{10}$$

转移满足 $e' \in [1200,10800]$ 且 $e'-e \in [-S/\eta,\ \eta S]$。最优费用 $F_1(6000) = 35126.948589$ 元。终端函数取**扩展实值指标函数**而非线性残值，因为题目要求日末储量严格等于日初值，用线性残值会改变问题。

### 7.2 命题 2（价值函数的凸分段线性）

> **命题 2**　在非负电价、恒定单程效率、允许未利用供能及给定首末储电量条件下，$F_t$ 在其有效定义域上为凸分段线性函数，且 $\Lambda_t(e) = -\partial F_t(e)$ 随 $e$ 单调非增。

**证明要点**：$\psi$ 为凸折线，正部算子单调非减且凸，故 $\varphi_t$ 为凸分段线性；把功率限制与库存区间写成指示函数 $\iota$ 后，

$$F_t = \iota_{[1200,\,10800]} \oplus \big(F_{t+1} \square \varphi_t^{R}\big) \tag{11}$$

其中 $\square$ 为下确界卷积、$\varphi_t^{R}$ 为 $\varphi_t$ 关于原点的反射。凸函数的下确界卷积与加法均保持凸性与分段线性，有限转移区间保证最小值可达；自终端指标函数按 $t=T,\dots,1$ 归纳即得。单调性由凸性 $(p_2-p_1)(e_2-e_1)\ge 0$ 直接得到，令 $w_i = -p_i$ 即 $w_1 \ge w_2$。$\square$

该性质保证价值函数可用**有限条折线**精确表示，充放电决策由"边际价值与价格阈值比较"给出，无需枚举。

### 7.3 斜率递推算法

1. 每个 $F_t$ 存为"左端点 + 左端函数值 + 各段斜率序列"；按式（11）反向递推，每步只做一次**斜率归并**（下确界卷积）与一次**定义域截取**，不建立 SOC 网格；
2. 反向时段费用至多 3 段，逐段归并后段数增长可控；
3. 由 $E_0 = 6000$ 正向回代，逐时段取 $\arg\min\{\varphi_t(x) + F_{t+1}(e+x)\}$ 恢复最优动作。

本实例单个价值函数最多 **22 段**、全天累计 **1985 段**，$F_1$ 在 $[1200,10800]$ 上共 **12 段**，全程无任何 SOC 离散化。

## 9 灵敏度分析

将其余参数固定，令待考察参数在原值上下 ±10% / ±20% 变动并重解，结果如下（`results/q1_sensitivity_wide.csv`，基准费用 35126.9486 元）。

**表 9-1 参数变动下的最优费用 / 元**

| 参数 | −20% | −10% | 基准 | +10% | +20% |
| --- | ---: | ---: | ---: | ---: | ---: |
| 储能容量上限 $C_{\max}$ | 36931.2238 | 35923.2009 | 35126.9486 | 34420.6236 | 33718.3790 |
| 充放电效率 $\eta$ | 40867.7028 | 37888.2491 | 35126.9486 | 32695.4474 | 23437.3212 |
| 最大充放电功率 $P_{\max}$ | 35247.8709 | 35156.5000 | 35126.9486 | 35103.8518 | 35083.2935 |

**表 9-2 相对基准的费用变化 / %**

| 参数 | −20% | −10% | +10% | +20% |
| --- | ---: | ---: | ---: | ---: |
| 储能容量上限 $C_{\max}$ | +5.1364 | +2.2668 | −2.0108 | −4.0099 |
| 充放电效率 $\eta$ | +16.3429 | +7.8609 | −6.9220 | −33.2782 |
| 最大充放电功率 $P_{\max}$ | +0.3442 | +0.0841 | −0.0658 | −0.1243 |

**解读**：

- **效率最敏感**：$\eta$ 下降 10% 使费用上升 7.86%，上升 10% 使费用下降 6.92%，且向上一侧呈明显加速（+20% 时费用降 33.28%）——因为 $\eta$ 同时进入充、放两个环节，其影响按 $\eta^2$ 放大；
- **容量次之**：容量上限 ±20% 带来约 ∓4%—5% 的费用变化，与 6.3 节影子价格指出的"瓶颈在可用容量"一致；
- **功率最不敏感**：最大充放电功率 ±20% 的费用变化不超过 0.35%，印证放电功率上界的独立边际值为 0。

结论：模型对效率与容量的合理偏差是稳健的（±10% 内费用变化 <8%），对功率参数几乎不敏感；真正决定费用的是电价形状与储能的能量搬运能力。
