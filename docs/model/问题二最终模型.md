## 1 总体结构

方法三是一个三层、单向串联的"预测 → 规划 → 执行"框架，每层职责严格分离，且全部**非前视**（不看未来真实值）：

```
实测数据 ─► ① 非前视融合预测(点预测 load_hat, pv_hat)
                        │
                        ├─► ② 历史情景两阶段随机规划 ──► 计划购电量 g_1..g_144
                        │        (30 条残差情景，M=30)
                        │
                        └─► ③ DP 价值执行器 ──► 保留水平 R_1..R_144
                                                     │
真实序列(load,pv,price) ─────────────────────────────┴─► 实时因果执行
                                                     └─► 充电/放电/紧急购电/弃能
```

三层职责：

- **预测层**：给出情景中心（负荷/光伏的 144 段点预测）——分解给水平、Ridge 给形状，二者融合。
- **规划层**：在不确定性揭晓前定下"必须签下的计划购电量" $g_t$。
- **执行层**：给出动态保留水位 $R_t$，决定实际运行时何时放电、何时守住库存。

## 3 第①层：非前视融合预测

预测层采用**分解⊕Ridge 线性加权融合**：负荷融合预测 = $w\cdot$分解预测 $+(1-w)\cdot$Ridge 预测，融合权重 $w$ 由此前 $\le$30 日样本外残差按含交叉项最小二乘滚动确定（典型 $w\approx0.75$）。分解分量给出预测**水平**（含工作日/休息日切换倍率 $\beta$ 的趋势外推）与基础**形状**；Ridge 分量以 25 维特征给出完整预测，水平与形状同时参与。

### 3.1 三个成分（`solve_q2_method3.py:117-158`）

| 成分 | 函数 | 口径 |
| --- | --- | --- |
| **分解预测** | `decomposition_trend` | 周五、周六视为低负载日；形状取此前**最近 3 个同类型日**的归一化平均形状，水平由前一日电量经工作日/休息日切换倍率 $\beta$ 趋势外推，两者相乘得到分解预测 |
| **Ridge 预测** | 官方面板 `data_processed/q2_forecasts_reg_ext.csv` | 25 维特征 + $\text{StandardScaler}\to\text{Ridge}(\alpha=1)$，非前视 walk-forward、每 7 天重训、预测截断 $\ge 0$ |
| **融合** | `fused_forecasts` | 线性加权：$w\cdot$分解 $+(1-w)\cdot$Ridge，$w$ 由此前 $\le$30 日残差含交叉项最小二乘滚动确定 |

### 3.2 融合公式

记分解预测为 $\hat L^{\text{dec}}_{d,t}$（日电量水平 × 归一化日内形状），Ridge 预测为 $\hat L^{\text{ridge}}_{d,t}$。融合权重 $w$ 由决策日之前 $\le$30 日样本外残差按含交叉项最小二乘滚动确定：

$$w_d=\mathrm{clip}\!\left(\frac{\sum_{j\in W}(\varepsilon^{R}_j-\varepsilon^{D}_j)\,\varepsilon^{R}_j}{\sum_{j\in W}(\varepsilon^{D}_j-\varepsilon^{R}_j)^2},\,0,\,1\right),\qquad W=\text{此前 30 日},\quad \varepsilon=\text{残差}$$

则**负荷融合预测**为两者的线性加权：

$$\hat L_{d,t} = w_d\,\hat L^{\text{dec}}_{d,t} + (1-w_d)\,\hat L^{\text{ridge}}_{d,t}$$

**光伏**不参与融合（问题二无附件 3 预报），直接取分解光伏（此前最近 $\min(3,\,d-1)$ 天实测光伏均值，非负）。全部量只用 `date < d` 的样本，**非前视**。

> 直观：分解擅长"今天大概用多少电"（水平）且对日内形状稳健，Ridge 擅长"日内几点高、几点低"（形状）并给出完整预测；由最小二乘在滚动窗口内自适应分配两者权重（实测 $w\in[0.598,0.993]$，均值 0.723）。**问题二与问题三使用同一套负荷融合方法**（分解⊕Ridge 线性加权），逐点完全一致；差别仅在光伏侧：问题三有附件 3 预报、问题二没有。

### 3.3 Ridge 成分的特征与训练协议

Ridge 形状项仍沿用 25 维特征（在 `forecast_q2.feature_panel` 的滞后/滚动面板上叠加 `add_harmonics` 的多阶谐波）：

- **滞后特征**：`lag1, lag2, lag7, lag14`（date×slot 宽表上平移）
- **滚动统计**：`mean3/7/14`、`std3/7/14`（均基于 `shift(1)`，只含当前日之前的历史）
- **日历**：`slot, dow, month, doy`
- **日内谐波**：`tod_sin1..4 / tod_cos1..4`（1–4 阶）
- **年内谐波**：`doy_sin1..2 / doy_cos1..2`（1–2 阶）

负荷与光伏**各自独立训练**两个 Ridge（target = `load_kwh` / `pv_kwh`）。

> **25 维特征口径（负荷 / 光伏各一套数值）**：两模型**共用同一套 25 维特征设计**，但取值分两类——
> - **日历与谐波类 15 维**（`slot, dow, month` ＋ 日内 8 个、年内 4 个谐波三角项）：仅是时间的函数，两模型取值相同；
> - **滞后与滚动类 10 维**（`lag1/2/7/14`、`mean/std 3/7/14`）：**按各目标自身的历史序列分别计算**——负荷模型的 `lag1` 取负荷前一日值，光伏模型的 `lag1` 取光伏前一日值，故两模型这 10 维数值不同。
>
> 特征总数 = 3（日历）＋ 4（滞后）＋ 6（滚动）＋ 8（日内谐波）＋ 4（年内谐波）= **25**，与 `forecast_q2_reg.FEATURES` 完全一致。

- **非前视 walk-forward**：预测第 $d$ 天只用 `date < d` 的样本训练（`solve_q2_method3.py:100`）。
- **每 7 天重训一次**（`i % 7 == 0`），其余日只更新滞后/滚动特征。
- **后处理**：Ridge 预测值截断到 $\ge 0$；光伏再截断到"仅用历史估计的同时段 0.995 分位晴空包络"（`solve_q2_method3.py:109-111`）。
- 为使残差库有历史，Ridge walk-forward 从 **2025-01-22** 起算（`lag14` 需要 14 天前置数据）。

## 4 第②层：历史情景两阶段随机规划

目标：在**不确定性揭晓前**定下全情景共享的计划购电量 $g_1..g_{144}$。

### 4.1 情景生成（`solve_q2_twolayer.py:263-266`）

- 取决策日**之前 30 天**的样本外残差（`RESID_WINDOW = 30`）：

$$\text{resid\_load}^\omega_t = L^\text{act}_{t,\omega} - \hat L_{t,\omega},\qquad
\text{resid\_pv}^\omega_t = V^\text{act}_{t,\omega} - \hat V_{t,\omega}$$

- **整日重采样**（按天整段抽取，保留 144 段日内相关性与负荷—光伏配对），得 **$M = 30$ 条等权情景**。
- 情景净负荷：$L^\omega_t = \max(\hat L_t + \text{resid\_load}^\omega_t, 0)$，$V^\omega_t = \max(\hat V_t + \text{resid\_pv}^\omega_t, 0)$。

### 4.2 两阶段 LP（`two_stage_plan`，`solve_q2_twolayer.py:96-148`）

决策分两级：

- **第一阶段（here-and-now）**：计划量 $g_t$，**全情景共享**，必须在不确定性揭晓前定下；
- **第二阶段（wait-and-see）**：$c_{t,\omega},\ d_{t,\omega},\ b_{t,\omega},\ u_{t,\omega},\ E_{t,\omega}$，**逐情景**决策。

目标函数（计划费用 + 期望 5 倍紧急费用 − 日末库存价值）：

$$\min_{g,\,c,d,b,u,E}\quad
\sum_{t=1}^{144} p_t\,g_t \;+\; \frac{1}{M}\sum_{\omega=1}^{M}\sum_{t=1}^{144} 5\,p_t\,b_{t,\omega}
\;-\; \frac{v}{M}\sum_{\omega=1}^{M} E_{T,\omega}$$

其中日末库存价值系数 $v = V\_CONT = 0.481548$ 元/kWh（`solve_q2_twolayer.py:40`），用 $-v\,E_{T,\omega}$ 表示"留到明天的电"的价值，避免优化把库存抽空。

约束（$\forall$ 情景 $\omega$、$\forall$ 时段 $t$）：

$$
\begin{aligned}
& g_t + b_{t,\omega} + d_{t,\omega} - c_{t,\omega} - u_{t,\omega} = L_{t,\omega} - V_{t,\omega}
&& \text{功率平衡（}g\text{ 共享）}\\[2pt]
& E_{t+1,\omega} = E_{t,\omega} + \eta\,c_{t,\omega} - d_{t,\omega}/\eta
&& \text{SOC 动态}\\[2pt]
& 0 \le c_{t,\omega},\, d_{t,\omega} \le S,\qquad b_{t,\omega},\,u_{t,\omega}\ge0
&& \text{电池功率限与外网/富余非负约束}\\[2pt]
& e_{\min} \le E_{t,\omega} \le e_{\max},\qquad E_{0,\omega} = e_0
&& \text{电量边界与初值}
\end{aligned}
$$

- **求解器**：`scipy.optimize.linprog(method="highs")`。
- **规模**：残差库完整时变量数 $= 144 + 30 \times 721 = 21\,774$；等式约束 $2\times144\times30 = 8\,640$。回测初期历史残差不足30天时按实际可用天数取样，直至窗口充满。
- **输出**：$g \in \mathbb{R}^{144}$（当日计划购电量）。

> 关键点：只有 $g$ 是全情景共享的，5 倍紧急费用按情景期望进入目标——这就是随机规划相对确定性 LP 的核心：**计划量必须为最坏情形留余地**。

## 5 第③层：DP 价值执行器

把上一步的 $g$ 当作"已签计划"，用动态规划的价值函数决定**何时该放电、何时该守住库存**，输出动态保留水位 $R_t$。

### 5.1 单时段反射费用函数（`build_h_tilde`，`solve_q2_twolayer.py:154`）

给定情景 $\omega$ 在时段 $t$ 相对计划的净需求 $r_{t,\omega} = (L_{t,\omega} - V_{t,\omega}) - g_t$，用储能"取用"净量 $y$ 的费用（凸分段线性函数精确表示）：

$$\tilde H_{t,\omega}(y) = 5\,p_t\,\bigl[\,r_{t,\omega} + \psi(-y)\,\bigr]^{+},\qquad
\psi(x) = \begin{cases} x/\eta, & x \ge 0 \\ \eta\,x, & x < 0 \end{cases}$$

- $r > 0$（缺额）：只能放电，$y \in [0,\ \min(S, r)/\eta]$；
- $r \le 0$（富余）：只能充电，$y \in [-\eta\min(S, -r),\ 0]$，该区间费用恒为 0。

### 5.2 反向递推 + 等权平均（`future_value_curves`，`solve_q2_twolayer.py:170`）

$$H_{T,\omega}(e) = -v\,e,\qquad
H_{t,\omega} = \Pi_{[e_{\min}, e_{\max}]}\bigl(\tilde H_{t,\omega} \;\square\; H_{t+1,\omega}\bigr)$$

其中 $\square$ 是**下确界卷积**（`infconv`）= 逐时段取最优决策的最小费用。凸分段线性结构下，$\square$ 的结果由两函数**斜率集合归并、对应定义域宽度相加**精确得到（`q1_two_layer.py:135-150`）；$\Pi$ 为定义域截断（`restrict`）。再对 $M$ 条情景**等权平均**：

$$\bar H_t(e) = \frac{1}{M}\sum_{\omega=1}^{M} H_{t,\omega}(e)$$

### 5.3 保留水位 $R_t$（`retention_levels`，`solve_q2_twolayer.py:220`）

$$R_t = \operatorname*{arg\,min}_{e \in [e_{\min},\, e_{\max}]}
\Bigl[\ \bar H_{t+1}(e) + 5\,p_t\,\eta\,e\ \Bigr]$$

（存在平台时取平台右端，`argmin_max`，`solve_q2_twolayer.py:201-217`。）

物理含义：**第 $t$ 时段放电前必须保有的最低库存水位**——把"现在多留 1 kWh 的边际机会成本 $5 p_t \eta$"折进未来费用曲线后取最优点。

### 5.4 实时因果执行（只用真实序列，`solve_q2_twolayer.py:275-291`）

对 $t = 1,\dots,144$，令 $r_t = (\text{load}_t - \text{pv}_t) - g_t$：

- **$r_t > 0$（缺额）**：

$$\text{dis}_t = \min\bigl(r_t,\ S,\ \eta_d\,(e - R_t)^{+}\bigr),\qquad
\text{emer}_t = r_t - \text{dis}_t$$

不足部分按 $5 p_t$ 紧急购电 → **只有 SOC 高于 $R_t$ 才放电**。

- **$r_t \le 0$（富余）**：

$$\text{chg}_t = \min\bigl(-r_t,\ S,\ (e_{\max} - e)/\eta_c\bigr),\qquad
\text{surplus}_t = -r_t - \text{chg}_t$$

- **SOC 更新**：$e \leftarrow e + \eta_c\,\text{chg}_t - \text{dis}_t/\eta_d$，并作为下一时段/次日初值。

> $R_t$ 是方法三相对方法1"即时因果执行"的本质改进：不再是"缺额就立刻放电"，而是**主动保留库存以对冲未来不确定性**，把 5 倍紧急购电压下来。

## 7 与方法1、方法2 的关系（消融定位）

| | 预测器 | 优化与执行结构 |
| --- | --- | --- |
| 方法1 | **融合** | 确定性日循环 LP + 即时因果执行 |
| 方法2 | 统计均值（同星期 35 天均值 / 近 7 天光伏均值） | 情景随机规划 + DP 执行器（含 $R_t$） |
| **方法3** | **融合**（同方法1） | **情景随机规划 + DP 执行器**（同方法2） |

方法三 = **方法1 的预测器 ⊕ 方法2 的优化/执行结构**；方法1 与方法3 **共用同一融合预测**，因此可做"预测贡献 / 结构贡献"的二维消融。
