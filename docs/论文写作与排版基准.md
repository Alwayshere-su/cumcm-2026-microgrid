# 论文写作与排版基准

## 1. 规范优先级

1. `format2026.md`：2026年官方硬性格式与提交要求，优先级最高；
2. `数模通用模板.md`：章节骨架、表格位置及本题内容组织参考；
3. `cumcm-step-review` 内置优秀论文写法指南：用于证据组织、公式说明、图后分析和语言润色，不得覆盖前两项。

发生冲突时按上述优先级处理。各赛区后续发布的更高要求须单独核验并追加记录。

## 2. 电子版与纸质版分离

- 电子版论文不得包含承诺书和编号专用页，第一页必须为摘要专用页；
- 纸质版第一页为承诺书、第二页为编号专用页、第三页为摘要专用页；
- 摘要含标题和关键词，原则上不超过一页，从摘要页开始以阿拉伯数字连续编页码；
- 正文不要目录且不超过30页；附录页数不限；
- 电子论文单文件采用PDF或Word之一，建议PDF，文件不超过20MB；
- 支撑材料另行压缩为RAR或ZIP，不超过20MB，且不得包含身份、学校或赛区信息。

## 3. 模板占位符处理

- `数模通用模板.md` 标题“基于集成学习的洪水概率预测”为原模板占位，不得进入本题论文；
- 本题标题暂定为“微网与外部电网电力调控策略”；
- `【公式：……】`、`【图表：……】`仅表示原PDF版式位置，必须替换为本题真实公式、图表和计算结果；
- Word公式使用原生OMML对象，独占一行居中、编号右对齐且全文连续；正文用中文全角括号引用公式；
- 不把公式截图或LaTeX源码文本直接放入正文。

## 4. 最终论文结构

摘要 → 问题重述 → 模型假设 → 问题分析 → 符号说明 → 数据预处理 → 问题一至问题四模型建立和求解 → 模型鲁棒性检验 → 优缺点分析 → 参考文献 → 附录。

分阶段审核期间允许按“问题重述—数据预处理—逐问建模”顺序追加到草稿；生成终稿时必须重排为上述结构。

## 5. 表格、图与附录

- 符号说明重建为“符号—含义—单位”三线表；
- 图内不放标题，图题置于图下；表题置于表上；正文先引用图表，图表后立即解释趋势、关键数值与实际意义；
- 附录A首先列支撑材料文件表，再给出全部完整、可运行且与正文数值一致的源程序；
- 附录文件名以项目真实文件为准，不沿用模板中的`q2.py`、`q3.c`、`q4.cpp`占位名称；
- 提交前核验论文、`result*.xlsx`、源程序、复现清单和支撑材料压缩包之间的一致性。

## 6. AI工具要求

论文还须遵守《全国大学生数学建模竞赛人工智能工具使用规定（2026年试行）》。全过程维护`ai_usage_log.md`；全文冻结后生成并审核AI工具使用声明及使用详情报告。官方固定文案与提交形式在最终阶段再次从官方来源核验。
