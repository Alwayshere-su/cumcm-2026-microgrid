## 2 逐项说明

### 2.1 特征维度：23 → 25

**问题**：`build_paper_draft.py` 有两处写 23：
- 式(15)：`\hat y_{d,t}=\beta_0+\sum_{j=1}^{23}\beta_j z_{d,t,j}`
- 正文："式（15）中 z 为标准化后的 **23 维**历史与周期特征"

**实际**：`scripts/forecast_q2_reg.py` 的 `FEATURES = BASE + HARM`，长度为 **25**：

| 组 | 个数 |
|---|---:|
| 日历 `slot/dow/month` | 3 |
| 滞后 `lag1/2/7/14` | 4 |
| 滚动均值 `mean3/7/14` | 3 |
| 滚动标准差 `std3/7/14` | 3 |
| 日内谐波 `tod_sin1..4, tod_cos1..4` | 8 |
| 年内谐波 `doy_sin1..2, doy_cos1..2` | 4 |
| **合计** | **25** |

"23" 的来源：草稿把 `doy`（年内日序 1–365）当作特征计数，但代码 `FEATURES` 中
**没有 `doy`**——季节由 `doy_sin/cos` 四项表达。13 + 12 = 25。

**修正**：式(15) 求和上限改为 25；正文改为"25 维历史与周期特征（13 个滞后/滚动/日历
特征与 12 个日内、年内谐波项）"，把构成写明，便于评审核对。

> 独立佐证：`岭回归相关性证据/README.md` §六 也指出了同一处 23 vs 25 不一致。

### 2.2 相关系数 0.9664：算法描述与数值不符

**问题**：正文原写"全年**归一化实现价形状**与附件1固定分时价**形状**的相关系数为 0.9664"。

**核实**（`scripts/verify_q4_price_corr.py`，5 种定义实测）：

| 定义 | 数值 |
|---|---:|
| 逐日归一化形状 vs 附件1形状（取日均） | 0.9712 |
| **形状中位数曲线 vs 附件1形状**（即图20画的两条线） | **0.9988** |
| 形状均值曲线 vs 附件1形状 | 0.9991 |
| 池化全部时段 vs 附件1形状 | 0.9221 |
| **扣除各自日均价后池化 vs 附件1去均值** | **0.9664 ← 正文这个数** |

**0.9664 对应的是"扣除各自日均价后的相关"**，不是"归一化形状 vs 形状"。
按论文字面算法应得 0.9988（图20两条曲线）或 0.9712。

**风险**：图20显示两条曲线几乎重合（0.9988），正文却写 0.9664，被追问时无法解释。

**修正**：两处均改为
> "把实现价与附件1固定分时价**各自扣除当日均价**后再作比较，二者相关系数为 0.9664"

并补上峰谷比对照（3.039 与 3.039），使"固定价能稳定识别高低价次序"这一论断有双重支撑。

### 2.3 补入 4-2 的关键收益

**问题**：正文只有 4-3 的机制描述，未给出 4-2 承诺规则的量化收益。

**权威值**（`harness_q4_summary.json` → `effects_42_yuan`）：

| 效应 | 金额 |
|---|---:|
| 价格信号（固定价→点预测） | +7,459 元（几乎无收益） |
| **承诺量（点预测→价格加权 4/5 分位）** | **−1,340,430 元** |

即 **4-2 的价格加权 4/5 分位承诺相对点预测承诺全年省 134.04 万元**，
是本问最显著的单一效应。

**修正**：正文补入"全年实测该承诺规则较点预测承诺节省 134.04 万元"。

### 2.4 建立数字一致性校验

**新增** `scripts/paper_metrics.py`：把散落在 `results/*.json` 的关键数字集中抽取，
并计算派生量（价格形状相关的多种定义、价格结构统计），统一写入

差异来源已定位为价格预测口径不同：

| 项 | 早先轮次 | 当前权威版 |
|---|---|---|
| 价格形状 | 30 日**均值** | 35 日**中位数** |
| 价格水平 | 7 日**均值** | 14 日**中位数** |
| 日内修正 | 未启用 | ρ=0.96，回看 6 段 |

（35 日形状 + 14 日水平 + ρ=0.96），**因此草稿的方法描述是对的**，
但引用 4-3 承诺效应结论时必须以本版为准，不能沿用早先"报童更优"的说法。

> 建议：论文中 4-3 的承诺规则仍需给出明确结论。若采用价格加权中位数，
> 需说明它相对点预测的费用差（+11.38 万元）为何仍可接受（如风险指标更优：
> CVaR₉₅ 49,858 与最坏日 104,662 相对点预测的 49,505/104,686 并非全面更优），
